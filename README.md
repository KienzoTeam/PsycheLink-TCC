## Como contribuir

- Aprenda GIT básico com esse repositório: [link](https://github.com/ImFenyx/Aprendendo-Git-e-Github)
- Faça `git clone <link do repo>.git` caso não tenha o repositório do TCC no computador
- Caso tenha, faça `git fetch` e `git pull` para ter atualizações
- Ao fazer um commit, siga a norma do [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/) usando a extensão do VSCode para ter nomes e descrição coesos nos commits, caso queira, pode usar ia pra nomear o commit.
- O commit não deve ser feito em zips para melhor manutenção, o commit deve ter a pasta inteira do jogo para que o git conte as modificações de cada arquivo e reversões sejam possíveis
